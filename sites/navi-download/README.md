# Navi download page

Public, static presentation of the approved Navi download UI. Installers are intentionally unavailable until released.

Source components were copied from the Agentech download UI on 2026-09-16. Links to About and the SDK point to the official website. No service routes, account code, or runtime secrets are included.

Run `npm install` and `npm run build` to export the page to `out/`.
