# AIGC introduction and content sections

The `/aigc` route is a visual introduction under Service. Asset, Asset Movement, and Full Animation are sections on this same page, with anchor navigation and empty content areas. Detailed offerings, media, and workflows are intentionally deferred until the owner supplies content. There is no AIGC account type, submission flow, pricing, or database schema in this introduction.

The header order is Platform, Service, Robotics, Education, Talents. Service contains AI Development, Data Collection, and AIGC. Robotics contains Robotics Rent and Robotics Sale, preserving their existing destinations.

Platform contains EAIC, EAIS, Skill Market, and NAVI STORE in that order. `/skill-market` reuses the existing `PlaceholderPage` and its animated Coming Soon robot scene.

The page uses its own `data-aigc-page` scope with the standard `#f5f4f1` light canvas and a dark palette. The artwork is explicitly captioned as an AI-generated concept.
